# Changelog

## 0.2.3

- Pots now sit flush on hot kitchen surfaces on Forge 1.20.1, fixing the floating-pot gap.
- Fixed a crash when using Farmer's Delight baskets with Create: Central Kitchen on Forge.
- Fridge ice upgrades now supply snowballs to cooking recipes correctly, without using up real snowballs from storage.
- Better compatibility with optional cooking mods and supported Cooking for Blockheads versions.
- Cookware on connected stoves is detected more reliably, and serving containers (bowls, etc.) are counted correctly.
